## Authorization status

OMEGA NEX-ORA is an owner-controlled, proprietary project. The project identity supplied for this documentation names Shajeduzzaman Enan as its builder. **Do not begin implementation,
modify project files, publish a modified build, or submit code intended for inclusion

## Authorized contribution process

1. Obtain written authorization and an agreed scope from the project owner before work begins.
2. Use an owner-approved branch and follow the project's security and test instructions.
3. Never include secrets, customer data, production dumps, signing keys, or private credentials.
4. Describe the change, threat impact, migration impact, and tests performed.
5. Wait for explicit owner review and approval before merge or release.
6. Do not publish or redistribute a modified copy unless the owner separately grants that right.

## Security-sensitive changes

Changes to authentication, authorization, key generation/redemption, HMAC handling,
secret configuration, migrations, RLS, session cookies, CSRF, deployment, or release
workflows require explicit owner review.
