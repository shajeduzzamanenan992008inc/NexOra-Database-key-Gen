## Contribution policy

Contributions are welcome for this repository. A pull request is not automatically accepted and does not itself transfer copyright. Before submitting, confirm that you own the contribution or have authority to submit it. A contribution may be merged as Covered Materials only after the Contributor explicitly agrees in writing to the non-commercial public grant described in Section 9 of the root LICENSE. Contributors retain ownership. Commercial relicensing requires separate explicit written consent or a Contributor License Agreement that expressly grants those rights.

## Required practices

1. Never include secrets, customer data, production dumps, signing keys, API tokens, passwords, or private credentials.
2. Describe changes, security impact, migration impact, and tests performed.
3. Follow existing architecture, formatting, test, and security guidance.
4. Authentication, authorization, key generation/redemption, HMAC, secret configuration, migrations, RLS, sessions, CSRF, deployment, and release changes require maintainer review.
5. Preserve copyright, attribution, third-party notices, and license requirements.
6. Do not submit third-party code or assets without confirming permission and required notices.
