# Security Policy — OMEGA NEX-ORA

**Project owner contact:** Use the verified private communication channel published by the project owner, Shajeduzzaman Enan. No unverified email address or contact endpoint is designated by this repository.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data, or a working attack against a
production service in a public issue. Use GitHub's private vulnerability reporting /
Security Advisories feature if it is enabled for this repository, or contact the project
owner through the verified private channel supplied by the owner. No email address is
invented in this file.

Include a concise description, affected component/version, impact, reproduction steps
that do not expose real user data, and any suggested mitigation.

## Scope cautions

- Never test against systems or accounts you do not own or have written permission to test.
- Do not access, alter, or retain another person's data.
- Do not publish secrets or full production logs in a report.
- Stop testing and report immediately if real credentials or personal data are exposed.

## Response

The project owner will assess reports, determine severity, and coordinate remediation
and disclosure. A response time is not promised by this template.
